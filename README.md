# TreningVane v1.11

## Ferdig intern versjon
- Appen er laget for lokal bruk og trenger ikke publiseres på Google Play.
- Planlegging, redigering, sletting og fullføring av aktiviteter er beholdt.
- Treningsbibliotek med søk, kategorier, favoritter, detaljer og direkte «Legg til i plan».
- Realistiske lokale bilder for løping, gåing, sykling, styrke, yoga, svømming, fotball og basketball.
- Statistikk og grafer for uke, måned og år.
- Streak og beste streak (med 3-dagers "nådetid" før brudd).
- Motiverende "Siste sjanse"-varsel på den 3. dagen uten aktivitet (kl. 17:00) for å redde streaken.
- Varsler kan slås av/på i Innstillinger.
- Light/dark mode med tilpasset status- og navigasjonslinje.
- Lokal Room-database uten konto eller sky-synkronisering.
- Validering ved planlegging og fullføring er beholdt fra tidligere versjoner.
- Unødvendig debug-logging for statistikk er fjernet i v1.11.
- Versjon: 1.11 / versionCode 11.

## Teknisk
- Kotlin + Jetpack Compose + Material 3
- Room database
- MVVM
- Navigation Compose
- MPAndroidChart
- targetSdk 36
